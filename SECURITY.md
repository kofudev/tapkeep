# Security

Studio listens on IPv4 loopback only. Its API requires a random token, checks the Host header, rejects foreign Origin headers and serves the interface with a restrictive content policy.

Recording and replay visit your selected app using Chromium. Replays perform real actions and can alter application data. Use test accounts and a test environment.

Sensitive input values become environment references. Other input, page text and URLs can remain in flow JSON; failure captures can contain application data. Review artifacts before sharing them.

Report vulnerabilities privately using the maintainer's GitHub profile. Include affected version and a minimal reproduction without credentials.
